ESP32 AI Lab — Privacy Policy

Applies to: the iPhone/iPad app “ESP32 AI Lab” (Chinese name ESP32 AI 實驗室, bundle ID tw.livingtech.esp32lab)　Effective: November 3, 2026 (tip-jar note added November 7, 2026)　Developer: Henry Chao (individual)

ESP32 AI Lab helps students learn to program ESP32 development boards. On an iPhone or iPad, students write or paste MicroPython code and send it to an ESP32 board on the same Wi-Fi network (running this project’s open agent program) to see its output, control it remotely and try vision recognition. Without a board, they can practice with the offline circuit simulator built into the app.

The developer runs no servers. The app needs no account or sign-in, shows no ads and contains no analytics or tracking SDKs. The app does not collect, upload, sell or share any data with third parties, and the developer cannot see any user data. The app only talks to devices you choose yourself (boards and a teacher’s computer on your local network), as described below.

The optional “buy the developer a coffee” tip is handled by Apple’s in-app purchase system; the developer never receives your payment details. Tips unlock nothing and change none of the above.

1. Local Network permission

  • The app needs Local Network access to find and connect to ESP32 boards on the same Wi-Fi (send code, read output, remote control) and to the classroom server on a teacher’s computer (class device list, one-tap updates).
  • These connections stay on your local network and never go through a developer server (there is none). If you decline, the examples, code editor and offline circuit simulator still work.

2. Camera permission and images

  • The app asks for camera access only when you start recognition on the Vision tab.
  • Frames are processed in real time on the device and are never recorded, saved or uploaded. Only the recognition result (for example “thumbs up 0.92” and a box position) is sent to the board so it can light an LED or show text.
  • If you decline, you can still try recognition with the built-in test images; nothing else is affected.

3. Custom recognition model (optional)

On the Vision tab you may enter a URL to download a Core ML model that you trained and exported from Teachable Machine. The app only downloads that file from the URL you entered and sends no data to it; the model is used on the device only.

4. Circuit simulator

The circuit simulator (parts, breadboard, MicroPython and the ESP32 emulation core) is bundled in the app and runs offline. It makes no network connections and sends no data.

5. Using it with a chat AI

The app offers prompt templates students can copy into a chat AI such as Gemini or ChatGPT to discuss code, then paste the code back into the app. The app itself does not connect to any AI service; anything students type into those services is covered by those services’ own privacy policies.

6. Storage and deletion

  • Code, pasted text, recent boards, the classroom server address and class code are stored in the app’s settings on this device, without iCloud sync.
  • The code editor has a one-tap “clear all code” option; deleting the app removes all data.

7. Children and students

The app is intended for middle and high school students in class or at home. It needs no account and collects no names, contact details or other personally identifiable information. Board names are codes generated by the board itself (for example esp32lab-7f2a) and contain no personal data.
