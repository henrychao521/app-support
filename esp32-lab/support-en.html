ESP32 AI Lab — Support

Applies to: the iPhone/iPad app “ESP32 AI Lab” (Chinese name ESP32 AI 實驗室, bundle ID tw.livingtech.esp32lab)　Effective: November 3, 2026　Developer: Henry Chao (individual)

About the app

Write MicroPython on an iPhone or iPad and run it on an ESP32 board instantly. Made for middle and high school technology and computing classes and self-study.

  • Devices: connect by board name (e.g. esp32lab-7f2a.local) or IP; see signal, version and memory.
  • Examples: built-in example programs you can run on a board or in the simulator with one tap.
  • Code / Paste: a line-numbered editor. Code pasted back from a chat AI is cleaned up, syntax-checked and screened before it runs for patterns that would disconnect the board or make it unstoppable (such as connecting to Wi-Fi in user code, while True, or re-initializing the display).
  • Console and Remote: board output and errors; joystick, buttons and sliders to control the board.
  • Vision: on-device recognition of gestures, faces, poses and objects with the camera, sending results to the board; Teachable Machine models are supported.
  • Circuit simulator: practice without a board. Drag LEDs, buttons, sensors and displays onto a breadboard, wire them up and run your code; a multimeter measures voltage and current.
  • Teacher: connect to a classroom server on the teacher’s computer to see every board in class and update them all at once.

Getting started

  1. No board: open the Circuit Simulator from the Devices tab, or pick an example on the Examples tab.
  2. With a board: on a computer, open the first-flash website in Chrome and flash MicroPython and the agent over USB, then set up Wi-Fi.
  3. Join the iPhone and the board to the same Wi-Fi and enter the board name on the Devices tab. Allow Local Network access when asked.

Supported boards

ESP32, ESP32-S2, ESP32-S3 (including LILYGO T-QT Pro, T-Display S3 and Seeed XIAO ESP32S3 Sense), ESP32-C3, ESP32-C6, ESP32-CAM and more. See the first-flash website for the current list.

FAQ

Can’t reach the board? Make sure both are on the same Wi-Fi (guest networks often isolate devices), turn on this app under Settings → Privacy & Security → Local Network, or use the IP shown on the board’s screen.

The program hangs? Tap Stop in the console, and write loops as while lab.running(): with lab.sleep(seconds) so Stop can interrupt them (all examples do this).

Does it cost anything? Ads? Free, no ads, no in-app purchases, no account.

Is my data uploaded? No. See the privacy policy.
