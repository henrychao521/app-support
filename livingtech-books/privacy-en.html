LivingTech Interactive Lab Privacy Policy

Applies to: iPhone and iPad App "LivingTech Interactive Lab" (Chinese name: 生科互動實驗室, Bundle ID: tw.livingtech.books)　Effective Date: October 27, 2026　Developer: Henry Chao (Individual)

"LivingTech Interactive Lab" brings together interactive modules from five living technology and engineering curriculum websites (Junior High Living Technology, Senior High Living Technology, Senior High Engineering Design, Taiwan Engineering Landscapes, and Circuit Practice Labs) along with a Python Coding Dojo in a single App, providing topic categories, search, favorites, recently opened items, and learning progress through a native interface. All curriculum content and the Python execution environment (Pyodide) are bundled inside the App for offline use, and code runs strictly on this device. This App requires no account and no sign-in, requests no system permissions, contains no ads and no analytics or tracking SDKs, does not use iCloud sync, and does not sell or share any data with third parties. The developer has no servers and cannot read user data.

On-Device Data and Offline Execution

  • Local Learning Records: Opened and completed modules, favorites (up to 300 items), recently opened items, and in-page interaction completion counts are stored exclusively on this device.
  • Web Module Answer Progress: Each web module's own answer progress is stored in the system WebKit's local web storage and remains only on this device.
  • Bundled Content and Python Runtime: All learning materials are packaged inside the App for offline availability. The Python runtime (Pyodide) for the Python Coding Dojo is also built into the App, and programs run strictly on this device.
  • Data Retention and Deletion: This App does not use iCloud sync. The developer operates no servers and cannot read user data. All data exists only on this device, and deleting the App deletes all data completely.

Permissions and Web-Layer Privacy Protection

  • No Permissions Requested: This App does not request any system permissions.
  • Active Web-Layer Blocking: To protect privacy, the App version actively blocks at the web layer the original websites' analytics/tracking scripts, Google Fonts, Google Sign-In and Google Drive, features that send answer records to spreadsheets (Google Apps Script), form submissions, multiplayer connections, and web geolocation requests (always denied). Teacher dashboard entry points are also hidden in the App version.

Limited Content Requiring Network Access

  • Map Basemaps and Photos: When connected to the internet, the map basemaps in "Taiwan Engineering Landscapes" download map tiles from the map servers of the National Land Surveying and Mapping Center (Ministry of the Interior) and Esri, and photos on a few pages are loaded from Wikimedia Commons.
  • Connection Information and Offline Behavior: These servers only receive standard information inherent to normal network connections (such as IP address and which image is requested); the App does not send any personal data. When offline, maps display a blank grid, photos are replaced with a "Network Required" card, and all other features work as usual.

External Videos and External Websites

YouTube videos and external interactive websites are not embedded or played directly inside the App; instead, a card is displayed. Only when the user taps the button will the link open in an in-App Safari view. Those external websites are governed by their own respective privacy policies.

Exporting, Sharing, and Email Links

  • Print, Download, Share, and Copy: Within the modules, "Print" generates a PDF, "Download" generates a file, and "Share" passes text or a URL. All three use the iOS system share sheet, allowing the user to choose whether to save to "Files", send via AirDrop, print, or share with a specific recipient. "Copy" only places content into the system clipboard. The App itself never transmits anything automatically.
  • Email Links: Email links (mailto) are handed off to the system Mail App.

Children and Student Privacy

This App includes interactive curriculum modules for junior high and senior high living technology and engineering design, making it suitable for students and general learners alike. The App requires no account and no sign-in, collects no personal data, and actively blocks spreadsheet answer submissions, form submissions, and multiplayer connections at the web layer. All learning progress and answer records remain solely on this device.
